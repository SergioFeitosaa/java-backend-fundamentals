## 📚 Topics covered

### ✅ Lambda
Functional interfaces and lambda expressions — the foundation of functional programming in Java.

- `Consumer` and `BiConsumer`
- `Function` and `BiFunction`
- `Predicate`
- `UnaryOperator` / `BinaryOperator`
- Method references

→ [View exercises](./lambda/)

---

### ✅ Stream API
Processing collections in a declarative and functional style.

- `filter()` — filtering elements by condition
- `map()` — transforming elements
- `collect()` — collecting results
- `forEach()` — executing actions
- `sorted()`, `distinct()`, `limit()`
- `count()`, `min()`, `max()`
- `findFirst()`, `anyMatch()`, `allMatch()`
- `reduce()` — reducing to a single value

→ [View exercises](./stream/)
